# 5기 최종 코테 : 점심 메뉴 추천

## 프로젝트 설명

---

각 코치에게 한 주의 점심 메뉴를 추천해 주는 서비스를 구현하였습니다.

## 기능 목록

---

### 입력

- [x]  코치의 이름을 쉼표(,)를 기준으로 입력받는다.
- [x]  각 코치가 못 먹는 메뉴를 쉼표(,)를 기준으로 입력받는다.

### 유효성 검사 (예외 발생 시 [ERROR] 메시지 출력 후 재입력)

- 공통
    - InputValidator
        - [x]  입력에 중복이 있는 경우
            - [ERROR] 입력은 중복될 수 없습니다.
        - [x]  쉼표로 구분했을 때 값이 없는(공백인) 경우 (예: 토미,,포코)
            - [ERROR] 입력하지 않은 값이 있습니다.
- 코치 이름
    - [x]  빈 값을 입력한 경우
        - [ERROR] 입력이 비어있습니다.
    - [x]  2 ~ 4글자 범위를 벗어난 경우
        - [ERROR] 코치의 이름으로 최소 2글자, 최대 4글자를 입력해야 합니다.
- 코치 수
    - [x]  2 ~ 5명 범위를 벗어난 경우
        - [ERROR] 코치는 최소 2명, 최대 5명 입력해야 합니다.
- 코치가 못먹는 메뉴
    - [x]  0 ~ 2개 범위를 벗어난 경우
        - [ERROR] 코치가 못 먹는 메뉴는 최소 0개, 최대 2개 입력되어야 합니다.
    - [ ]  메뉴판에 없는 메뉴인 경우
        - [ERROR] 메뉴판에 없는 메뉴가 입력되었습니다.

### 메인 로직 실행

- [ ]  주어진 카테고리를 랜덤으로 정한다.
    - `Randoms.pickNumberInRange()`의 결과가**1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식**을 추천한다.
    - [ ]  만약 이미 2번 추천한 카테고리인 경우 다시 정한다.
- [ ]  각 코치가 먹을 메뉴를 추천한다.
    - [ ]  정해진 카테고리에 있는 메뉴를 임의의 순서로 섞은 후, 첫 번째 값을 사용한다.
    - [ ]  추천할 수 없는 메뉴인 경우 다시 섞은 후 첫 번째 값을 사용한다.
    - [ ]  해당 코치 별 이미 추천한 메뉴와 중복되는 메뉴라면 다시 정한다.
- [ ]  위 과정을 월요일 ~ 금요일까지 반복한다.

### 출력

- [x]  서비스 시작 문구를 출력한다.
- [ ]  서비스 종료 문구를 출력한다.
    - [ ]  요일을 출력한다.
    - [ ]  카테고리를 출력한다.
    - [ ]  각 코치 별 추천할 메뉴를 출력한다.
